# Tabib.ma — Telemedicine & Doctor Booking

Morocco has 1 doctor per 1,600 people in rural areas. Urban specialists have 3-week wait times.

## Problem
Patients can't discover, book, or consult doctors online. Clinics manage appointments by phone.

## Solution
Three-sided marketplace: patients book consultations, doctors manage availability, clinics onboard their staff. Video consult + e-prescription + CMI payment.

## Stack
Java Spring Boot 3 (REST API), React 18 + TypeScript, PostgreSQL 16 + pgvector (symptom matching), Spring Data JPA, Spring Security + JWT, WebRTC video, CMI payment gateway, Docker (deployment)

## Completes
Riaya (childcare → healthcare) — same 3-sided marketplace architecture

## Key Roles
Patient | Doctor | Clinic Admin | Platform Admin
